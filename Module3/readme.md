# Module 3 - Cryptography Assignment

## Overview
This project demonstrates three core cryptographic concepts as required.

## Features

### 1. SHA-256 Hash Generation (`hash.js`)
- Generates SHA-256 hash for input strings
- Generates SHA-256 hash for files (integrity verification)

### 2. Caesar Cipher (`caesar.js`)
- Simple substitution cipher
- Encrypts and decrypts text using a user-defined shift

### 3. Digital Signature (`signature.js`)
- Uses RSA private/public key pair
- Signs data and verifies signature

## How to Run

```bash
npm install
node hash.js
node caesar.js
node signature.js
